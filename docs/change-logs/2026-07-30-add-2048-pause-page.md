# 2048 暂停页面

日期：2026-07-30

## 修改目标

按 2048 后续计划新增 PAUSE 暂停页面，让游戏中 SET 键进入暂停菜单，并提供继续、重新开始、返回主页三个完整流程。

## 修改前行为

SET 键由页面管理器全局处理，任何页面按 SET 都直接进入 SETTINGS。2048 游戏中没有 PAUSE 页面，暂停、继续和从暂停菜单重开只能通过回主页或游戏内 OK 重开绕行。

## 修改后行为

GAME 页面按 SET 进入 PAUSE 页面。PAUSE 页面显示 `RESUME`、`NEW GAME`、`HOME` 三项，支持 UP/DOWN 选择，OK/RIGHT 确认，LEFT 或 RST 短按返回 GAME。选择 `RESUME` 保留当前棋盘继续游戏，选择 `NEW GAME` 重置棋盘后返回 GAME，选择 `HOME` 返回 HOME。非 GAME 页面按 SET 仍进入 SETTINGS。

## 逻辑变化范围

- 新增 `UI_PAGE_PAUSE` 页面枚举和 `PAGE_PAUSE_OPS` 路由项。
- 新增 `page_pause.c/h`，实现三项暂停菜单、焦点动画、继续、重开、返回主页。
- 修改页面管理器：GAME 页面收到 SETTINGS 事件时进入 PAUSE，其它页面保持进入 SETTINGS；BACK 在 PAUSE 中返回 GAME，其它子页面仍返回 HOME。
- 在 GAME 页面暴露 `Page_Game_RestartFromMenu()`，供 PAUSE 页面重开游戏时复用现有棋盘重置和输入锁逻辑。
- Keil 工程加入 `page_pause.c/h`。
