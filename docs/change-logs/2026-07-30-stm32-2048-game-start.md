# STM32 2048 游戏起步

日期：2026-07-30

## 修改目标

按交接规划启动 2048 新主线：保留现有 ST7789、DMA 条带刷新、按键、页面和 INFO 诊断基础，新增一个无动画的可玩 2048 第一版，并把 HOME 第一项从旧 PLAYER 动画占位页切换到 GAME。

## 修改前行为

HOME 第一项进入 `PAGE_PLAYER_OPS`，该页面只显示程序生成的动画占位和播放状态，不包含 2048 棋盘、移动、合并、分数、胜负或重开逻辑。Keil 工程未包含独立游戏规则模块。

## 修改后行为

HOME 第一项显示 `2048`，确认或右键进入 GAME 页面。GAME 页面初始化 4x4 指数棋盘，显示当前分数、最好分数、16 个方块、WIN/GAME OVER 状态，支持摇杆四方向移动、合并、生成新块、无效移动不生成新块、OK 重开、RST 经全局 BACK 返回 HOME。

## 逻辑变化范围

- 新增 `game_2048.c/h`，实现固定内存 4x4 棋盘、LCG 随机数、初始化/重开、四方向移动、合并计分、胜利和失败判断、分数读取和单元格读取。
- 新增 `page_game.c/h`，实现 2048 页面绘制、按键事件映射、90 ms 有效移动节流、棋盘和分数局部重绘。
- HOME 第一项从 PLAYER 切换为 GAME。
- 页面路由从 `PAGE_PLAYER_OPS` 切换为 `PAGE_GAME_OPS`。
- Keil 工程从编译 `page_player.c/h` 改为编译 `game_2048.c/h` 和 `page_game.c/h`。

## 接口与兼容性

- 新增 `Game2048_*` 规则接口，当前仅被 GAME 页面调用。
- `UI_PageId` 中原 `UI_PAGE_PLAYER` 被替换为 `UI_PAGE_GAME`，页面枚举顺序保持 HOME/GAME/SETTINGS/INFO，未改变页面总数。
- SET 键仍保持全局打开 SETTINGS 的既有行为；本次未实现 PAUSE 页面。
- 未使用动态内存，未引入全屏 framebuffer，未改变 LCD、DMA、按键 GPIO 或底层驱动接口。
